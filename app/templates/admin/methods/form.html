How the integration works
  1. The client chooses this method. The CRM creates a unique reference and POSTs JSON to the API URL: reference, {{ "amount, currency, description, " if scope == "payment" else "date_of_birth, " }}client_id, email, first_name, last_name, country, callback_url, return_url, signed in the signature header (hex HMAC-SHA256 of the body).
  2. The provider answers with the unique URL; the client is redirected there.
  3. The provider POSTs the result (JSON or form) to the callback URL, signed the same way, with the reference and status{{ " and amount" if scope == "payment" else "" }}.
  4. {{ "Success credits the deposit (or waits for finance); failure rejects it." if scope == "payment" else "Success approves the client; failure rejects them with the reason." }} Every callback is logged below.
